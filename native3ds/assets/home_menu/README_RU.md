# Оформление HOME Menu

- `icon.png` — значок приложения, ровно 48×48 px.
- `banner.png` — постер системного баннера, ровно 256×128 px.
- `home_menu_jingle.ogg` — переданный пользователем фрагмент `Disney W (mp3cut.net)(1).mp3`.

Аудио сохранено как stereo Vorbis, 32 kHz, длительностью 2,94 с. В начале
добавлен fade-in 0,45 с, в конце — короткий fade-out 0,17 с для устранения
щелчка на границе обрезанного фрагмента. Исходный MP3 не изменялся.

Workflow собирает из этих файлов `witch_tetris_3ds_rc2.smdh` и
`witch_tetris_3ds_rc2.bnr`. Для SMDH включён флаг `allow3d`, а постер помещён
в штатную CGFX-сцену баннера Nintendo 3DS.
