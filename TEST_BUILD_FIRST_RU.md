# W.I.T.C.H. Tetris — 6.39-test1

Тестовая сборка продолжает 6.38-test2 на основе main 3e0889e (6.37.1). Это исходная Pygame-игра
со всеми ресурсами, а не EXE/APK. Проверяется на Python 3.12 / Pygame 2.6.1.

## Запуск

Полностью распаковать полный архив в отдельную папку. Папка assets должна быть
рядом с main.py. Windows: START_Windows.bat. macOS: START_macOS.command.
Скрипт создаёт локальную .venv и при первом запуске устанавливает Pygame
(нужен интернет). На компьютере должен быть установлен Python, для этой сборки
использован Python 3.12.

Если .command не открывается, в Терминале перейти в папку игры и выполнить:

```sh
bash START_macOS.command
```

Ручной запуск / Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python playtest.py
```

Меню тестирования: мышь или клавиши 1–7. Пункт 2 сразу запускает новую игру
«Калеб против Охотника». После закрытия игры меню можно открыть
повторным запуском стартового файла. Обычный вход без меню: `python main.py`
из окружения с Pygame.

Небольшой пакет UPDATE содержит только новые/изменённые файлы. Если исходная
игра 6.37.1 уже скачана из репозитория, распаковать UPDATE в её отдельную копию,
согласившись на замену совпадающих файлов. Существующую папку assets не удалять.
Полный архив FULL не требует предварительно скачанной игры.

## 1. BLUNK TREASURE ESCAPE

Переработана только эта мини-игра; отдельная Snake и все другие игры сохранены.

- ← — назад, → — вперёд. У сундука каждое дополнительное нажатие → берёт сокровище.
- Каждое сокровище даёт 1 очко; возвращение с добычей в лодку — ещё 3.
- Без добычи возвращаться в лодку нельзя. Искусственного лимита мешка нет.
- Седрик остаётся на месте. Четыре конечности выдвигаются/убираются по сегментам.
  На концах находятся четыре разные головы монстров из WILL MAZE.
  Полностью выдвинутый кончик ловит Бланка на соответствующей позиции,
  включая случай, когда Бланк сам шагнул в занятую позицию.
- Три жизни. На 200/500 очках каждого цикла 1000 потерянные жизни восстанавливаются.
- Темп увеличивается внутри сотни очков и снижается на следующей сотне.
- 1 — новая Game A; 2 — новая более быстрая Game B. Эти кнопки сбрасывают счёт.
- ESC / X — выход в коллекцию; после поражения SPACE / ENTER — новая попытка.

Правила повторяют основной цикл классического Octopus; точные аппаратные тайминги
и случайный генератор Nintendo не эмулируются. Требуется пользовательская проверка
темпа атак и читаемости опасных позиций. Видео https://www.youtube.com/watch?v=yi0iMQmi6hc
не удалось открыть; ранее правила сверены с руководством Game & Watch Gallery
и материалом https://learn.adafruit.com/game-watch-octopus.

В test2 используется сохранённый в репозитории портрет Седрика и рисуемые игрой
змеиные конечности/хвост. Присланные полноразмерные изображения исчезли из временной
среды вместе с первым архивом. Для точной подстановки позы с раскрытыми руками
достаточно вернуть PNG в `assets/minigames/cedric/serpent_open.png` и перезапустить
игру: загрузчик автоматически использует его вместо портрета. Файл должен быть
в исходном формате изображения; переименование другого формата не меняет его пиксели.

## 2. Выбор на 200+

Пункт 2 меню сразу открывает существующий выбор победителя, не требуя набрать 200 линий.

- Фобос собирается из летящих пиксельных фрагментов в существующую action-позу,
  смеётся существующей аудиорепликой, показывает злодейскую фразу и продолжает игру.
  Можно использовать SPACE / ENTER / ESC для продолжения сразу.
- Стражницы подпрыгивают, используя action-позы там, где они есть. Появляется
  «Ура! Победа!» и одна случайная реплика одного случайного включённого персонажа.
  Новые реплики победы пока текстовые, без новой озвучки.
- Отключённые персонажи не показываются и не выбираются для реплики.
- Автопродолжение примерно через 7 секунд (Фобос также завершает свой смех).
- Существующая сцена распада Стражниц в 20%-ветке обычных фигур сохранена;
  после неё начинается сборка Фобоса.
- Поражение после выбора Фобоса ведёт сразу в переход к его комнате, без Game Over.
  Существующие crash/blackout остаются частью перехода. Пункт 5 меню проверяет его.

## 3. Секретные коды

Вводить непосредственно во время обычного Тетриса:

- `phobos` / `фобос` — смех (если речь Фобоса разрешена выбранной веткой).
- `guardians`, `witch`, `стражницы`, `стражничы`, `чародейки`, `витч`,
  `кондракар`, `kandrakar` — всё поле очищается, появляется «ТАК НЕЧЕСТНО».
  Очки/линии не добавляются, отложенное начисление за старую очистку отменяется.
- Отдельные имена Стражниц и буквы фигур поле не очищают.
- `vtd`, `втд`, `валентин` — песня, эффекты, портрет. Реплики не звучат до конца
  песни и снова разрешаются после её окончания. Бесконечной блокировки нет.
  Явно включённый пользователем музыкальный повтор остаётся доступен.

В комнате Фобоса (пункт 3 меню, дождаться самой комнаты):

- `phobos` / `фобос` — «Спасибо».
- `guardians`, `witch`, `will`, `irma`, `tarani`, `taranee`, `haylin`, `cornelia`,
  `стражницы`, `стражничы`, `чародейки`, `витч`, `вилл`, `ирма`, `тарани`, `хайлин`,
  `корнелия`, `i`, `j`, `l`, `t`, `o`, `z`, `s` — одна из четырёх реакций из задания.
- Регистр неважен. Одиночной букве нужна пауза 0,6 секунды, чтобы не перехватить
  ввод полного имени (например, `i` в `irma`).
- Для VTD-алиасов общий счётчик: 1 — «Я не знаю, кто это»; 2 — «Не понимаю,
  о чём ты»; 3 — молчание; 4–11 — случайная цепочка Валентина из полного банка;
  с 12 — «Мне надоело играть в это».
- Последние четыре VTD-цепочки временно исключаются из выбора. Матричные цепочки
  имеют отдельный зелёный эффект; редкое Matrix-комбо имеет вероятность 5%.
- Присланный Markdown является источником текста, поэтому пустой или повреждённый
  старый `valentin_lines.json` больше не ломает сцену.
- Звуковой смех Фобоса в комнате отключён. Авторские текстовые реакции сохранены.
- Остальные секретные эффекты обычного Тетриса в комнате не запускаются.

## 5. CLASSIC

Независимые seven-bag при полном составе, ghost piece, задержка фиксации 0,5 с,
максимум 15 сбросов задержки на фигуру; удержание ←/→ с DAS 10 кадров / ARR 3.
При отключении персонажей мешок содержит только включённые фигуры.
Z — вращение против часовой, X/W — по часовой. Сохранены ↑ hard drop,
↓ soft drop, Shift/C hold, SPACE pause. Полный SRS/Guideline не заявляется.
Start Speed по-прежнему меняет скорость, а не сюжетные линии.
