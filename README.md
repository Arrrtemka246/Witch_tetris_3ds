# W.I.T.C.H. Tetris — The Spell of Phobos

Тестовая сборка **v6.37.1** фанатской некоммерческой игры по вселенной «Чародеек» (W.I.T.C.H.). Проект сочетает классический тетрис, визуальную новеллу, сюжетные развилки, ломание четвёртой стены, секретные коды и отдельные мини-игры.

Игра предназначена для личного тестирования автором и ограниченным кругом знакомых. Все права на исходную вселенную и персонажей принадлежат их правообладателям.

## Быстрый запуск

Требуется Python 3.11+ и Pygame 2.6+.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 main.py
```

В Windows активация окружения выполняется командой:

```powershell
.venv\Scripts\activate
py -m pip install -r requirements.txt
py main.py
```

Скачать текущую тестовую ветку целиком можно через **Code → Download ZIP**, предварительно выбрав ветку `codex/v6.37.1`. Прямая ссылка также находится в `DOWNLOAD_V6_37_1_RU.md`.

## Сюжетные этапы

- 0–99 линий: Фобос контролирует превращённых персонажей.
- 100–199: сопротивление усиливается, запускается сюжетная кат-сцена.
- 200 линий: выбор победителя — Стражницы или Фобос.
- Ветка Стражниц: свободная игра с классическими блоками и отдельной музыкой.
- Ветка Фобоса: 80% шанс хоррор-фигур и 20% шанс обычных фигур без персонажей.
- Ветка Фобоса: комната открывается при достижении 300 линий или немедленно после поражения.

## Основное управление

- `←` / `→` или физические `A` / `D` — движение фигуры.
- `↓` или физическая `S` — мягкое падение.
- `↑` — мгновенное падение.
- физические `W`, `X` или `Z` — вращение независимо от раскладки клавиатуры.
- `C` или `Shift` — HOLD.
- `Space` / `Esc` — пауза.
- `M` — включить или выключить музыку.
- `Shift+Q` — добавить 10 линий для тестирования сюжета.
- `F11` или `Cmd/Alt+Enter` — полноэкранный режим.

У мини-игр собственные подсказки управления отображаются на экране.

Подробное русское объяснение трёх одноэкранных игр и нового управления Cornelia Earth Garden находится в [`GAME_WATCH_MINIGAMES_GUIDE_RU.md`](GAME_WATCH_MINIGAMES_GUIDE_RU.md).

## Что добавлено в v6.37.1

- Полностью переделан фон комнаты Фобоса: присланная комната, огненный Меридиан за окнами и стол сведены в одну устойчивую композицию.
- Подключены шесть новых сидячих поз Фобоса. Белый фон удаляется отдельно от тёмного костюма, поэтому в плаще больше нет альфа-дыр.
- Повреждённая анимация Фобоса перед выбором победителя заменена цельной позой с лёгким программным движением.
- Секретные коды `MATRIX`, `PORN`, `JETIX`, `VTD` и русские варианты полностью отключены внутри комнаты.
- После проигрыша в выбранной ветке Фобоса обычное меню Game Over больше не появляется — игра автоматически переходит в комнату.
- Cornelia Earth Garden значительно усложнена: три цвета резонанса на `1/2/3`, прочность лоз, меньший радиус очистки, двойные волны и наказание за неверный цвет.
- Добавлен уникальный трек `forarcade.mp3` как `arcade_6.mp3`. Три остальных присланных файла не добавлялись повторно, потому что уже совпадали с существующими файлами побайтно.
- Добавлено отдельное руководство по механике, управлению и лоровому смыслу актуальных Game & Watch-игр.
- Секретные слова теперь принимаются только во время активного основного Tetris: не в меню, паузе, Game Over, мини-играх или кат-сценах.
- В комнате Фобоса огненный Меридиан сохранён отдельным слоем и очень медленно движется за оконными рамами; интерьер, Фобос и передний план остаются независимыми для будущего порта на 3DS.
- Озвучка пунктов главного меню и меню паузы Фобосом отключена.
- В настройках `GAME` появился пункт `ПАДЕНИЕ ФИГУР`: `ФОБОС` сохраняет управляемый хаос и выбран по умолчанию, `КЛАССИК` использует два последовательных мешка фигур без повторов внутри каждого мешка.
- В Cornelia Stone Covers четыре провала заменены лицами Will, Irma, Taranee и Hay Lin; безопасные сферы Irma Whirlpool теперь синие.
- Hay Lin Rescue удалена из Collection и игрового кода по решению автора.
- Irma Dark Water Panic расширена до пяти дорожек и постепенно ускоряется каждые 18 секунд без защитной паузы после наполнения сосуда.
- Добавлены два новых трека меню; они проигрываются через перемешиваемую очередь и доступны для прослушивания в Collection.
- Случайно загруженный 145-секундный `failed_last_time.wav` исключён из Game Over, но оставлен в репозитории как неиспользуемый файл до отдельного решения об удалении.

Полный журнал находится в [`V6_37_1_CHANGES.md`](V6_37_1_CHANGES.md).

## Известные отложенные вопросы

По решению автора в этой версии **не исправляются**:

- управление фигурой во время анимации удаления линий;
- конфликт клавиши `X` в Phobos Tetris.
