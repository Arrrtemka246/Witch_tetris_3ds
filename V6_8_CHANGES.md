# W.I.T.C.H. Tetris v6.8

- VTD music is now an exclusive soundtrack mode. Normal phase music cannot start underneath it, including on phase changes and loop toggles.
- Leaving VTD explicitly restarts the correct current phase soundtrack.
- Added repaired `menu_body_opaque.png`: Phobos' dark robes keep their black/burgundy pixels instead of being mistaken for transparent background.
- Phobos idle animation is slightly more active in menu and gameplay: slow breathing/weight shift plus a subtle talking pulse while voice audio plays.
- Added mouse/trackpad hover + click support to NEW GAME / RECORDS / QUIT.
- Added mouse/trackpad support to pause menu.
- Game Over now has selectable RESTART / MAIN MENU buttons with keyboard and mouse support.
- Existing keyboard controls and secret-code input remain intact.
