# Оформление Nintendo 3DS для W.I.T.C.H. Tetris

Эта папка предназначена для ресурсов HOME Menu и будущих CIA-сборок.

## Что будет в финальной CIA

- нормальная иконка приложения в HOME Menu;
- короткое и длинное название;
- имя автора/издателя;
- баннер при выборе игры;
- короткий звук баннера;
- отдельный вариант баннера с настоящим эффектом глубины, если будут подготовлены раздельные слои.

## 1. Иконка

Финальный формат для SMDH:
- большая иконка: 48x48;
- маленькая иконка: 24x24.

Что лучше прислать:
- master PNG 512x512 или 1024x1024;
- квадратная композиция;
- без мелкого текста;
- ключевой объект должен хорошо читаться после уменьшения до 48x48.

Предлагаемое имя исходника:
`branding/icon_master.png`

Из master-файла будут сделаны:
- `branding/icon.png` — 48x48;
- SMDH / icon.icn для CIA.

## 2. Баннер HOME Menu

Для обычного плоского варианта:
- PNG 256x128;
- главный объект лучше держать ближе к центру;
- важный текст не располагать вплотную к краям.

Предлагаемый master:
- 512x256 или 1024x512, затем уменьшение до 256x128.

Предлагаемое имя:
`branding/banner_flat_master.png`

Финальный файл:
`branding/banner.png` — 256x128.

## 3. Настоящий 3D-баннер

Если нужен не просто рисунок, а ощущение объёма на верхнем экране 3DS, лучше подготовить сцену слоями.

Минимальный набор:
- `banner_bg.png` — фон;
- `banner_mid.png` — средний план;
- `banner_fg.png` — передний план;
- `banner_logo.png` — логотип отдельно;
- при необходимости отдельные персонажи PNG с прозрачностью.

Рекомендуемый master для каждого слоя:
- 512x256 или 1024x512;
- одинаковый canvas;
- прозрачный фон у всех слоёв кроме background.

Также нужен короткий текстовый файл `depth.txt`:
- что должно быть дальше всего;
- что ближе;
- какие элементы не должны смещаться;
- желаемая сила 3D-эффекта: слабая / средняя / сильная.

Из этих материалов позже собирается отдельный CGFX-баннер и затем `banner.bnr`.

## 4. Звук баннера

Нужен короткий джингл, который звучит при выборе игры в HOME Menu.

Что прислать:
- WAV;
- PCM 16-bit;
- stereo или mono;
- без длинной тишины в начале;
- лучше короткий узнаваемый фрагмент.

Рекомендация по длительности:
- примерно 2–5 секунд, чтобы звук не раздражал при навигации по HOME Menu.

Предлагаемое имя:
`branding/banner.wav`

Если будет длинный исходник, можно прислать его целиком и отдельно указать нужный фрагмент.

## 5. Текст карточки

Нужно окончательно утвердить три строки:

Short title:
`W.I.T.C.H. Tetris`

Long title:
`W.I.T.C.H. Tetris — The Spell of Phobos`

Publisher / author:
`УТОЧНИТЬ`

Можно сделать английский и русский варианты метаданных отдельно.

- сборка banner.bnr;
- упаковка ресурсов в CIA;
- проверка, что иконка, текст и баннер корректно встроены;
- отдельная тестовая CIA для проверки на реальной 3DS.

## 7. Минимум, который можно прислать первым сообщением

Если хочется начать быстро, достаточно четырёх вещей:

1. квадратный арт для иконки;
2. широкий арт для баннера;
3. короткий WAV или исходный трек с указанием нужного куска;
4. точное имя автора/издателя для карточки.

Для настоящего 3D-варианта позже добавим раздельные слои.
