## Запуск

Полный архив распаковать в отдельную папку. Нужен Python 3.12.
Windows: START_Windows.bat. macOS: START_macOS.command (при необходимости разрешить запуск через chmod +x).
Или: `python -m pip install -r requirements.txt`, затем `python main.py`.

Небольшой архив UPDATE распаковать поверх актуальной версии из репозитория:
main.py должен оказаться рядом с прежним main.py, assets объединяется с assets.
Рекорды и настройки обновление не заменяет.

Проверка только финала: `python preview_ending.py`.

## Финал

Запускается после поражения при выборе Стражниц.
0–14: авторские титры справа, вращающееся Сердце слева, чёрный фон.
14–18: наступление портретов противников и мышей, бегущий Бланк.
18–22: бой Стражниц и Калеба; 20–22 — общий финальный удар по Седрику.
22–24: герои занимают места по композиции финального арта.
24: появляется арт с Фобосом; 26: переход с пиксельным распадом к арту W.I.T.C.H.
Затем благодарность; после окончания музыки и двух секунд — любая клавиша возвращает в меню.
Использованы оригинальные изображения пользователя, позы выделяются при загрузке.
Это программная спрайтовая анимация, не покадровый мультфильм.
Два финальных арта немного различаются, поэтому помимо частиц используется плавный переход всей композиции.

Первый трек каждой новой игры — Arrogant_Prince_of_the_Obsidian_Court.
Первый Escape в комнате Фобоса запускает вступительную цепочку, следующие — другие реакции.
«Так не может кончиться» звучит при распаде до выбора в третьей сцене.
Две угрозы в конце второй сцены выбираются 50/50.
Голосовые реакции на очистку линий после выбора Фобоса отключены.

## Исполняемые сборки

EXE и DMG в этот архив не входят и не проверялись на Windows/macOS.
На нужной системе: `python -m pip install -r requirements.txt pyinstaller`,
затем `python build_desktop.py`.
Windows: распространять всю папку dist/WITCH_Tetris, а не один EXE.
macOS: сценарий создаёт приложение и DMG; цифровой подписи нет.

Перед окончательным выпуском проверить звук и темп финала на своём компьютере.

В rc9 исправлен аварийный вылет при первом нажатии клавиши: состояние кодов экрана выбора теперь вычисляется до его использования.

В rc10 добавлена папка `assets/audio/music/cutscenes/guardians_win`: положите туда MP3/OGG/WAV для короткой сцены победы Стражниц. В этой сцене нет голосов, она ждёт любую клавишу, а после перехода в свободный режим отключены голоса Стражниц и код Фобоса.
